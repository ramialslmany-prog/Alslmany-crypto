Historical replay

The replay runs the same analyser, the same risk manager and the same broker the live bot uses. It decides on a bar’s close and fills on the next bar’s open; when one bar contains both the stop and the target it takes the stop; and it charges fees and adverse slippage on every entry and exit. These make the result worse than a naive backtest, which is the point.
